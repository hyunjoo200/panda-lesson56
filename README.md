# 중국어 탐험대 · 5·6차시 복습 — 판다의 생일 파티 🎂

6차시 마지막 8분에 하는 **말판 게임**입니다. 점프·구덩이 없이 누르기만 하면 돼요.
주사위는 중국 손숫자 사진으로 나오고, 학생이 손 모양을 보고 몇 칸인지 골라야 움직여요(맞히면 별 +5).

## 문제 10개 (복습 2개 = 20%)
| 칸 | 문제 | 내용 |
| --- | --- | --- |
| 복습 오솔길 | 1. 성조 암호 | (1차시) 妈·麻·马·骂 세 글자 듣고 성조 번호 누르기 |
| | 2. 짝꿍 대답 | (2차시) 对不起 → 没关系 |
| 숫자 언덕 | 3. 비밀 암호 | 숫자 세 개를 한 자리씩 듣고 누르기 |
| | 4. 四일까 十일까 | 四 sì / 十 shí / 七 qī 구별 |
| | 5. 손가락 암호 | 손숫자 사진 세 장 → 숫자 세 개 |
| | 6. 두 자리 수 | 三十六 듣고 36 고르기 |
| 생일 골목 | 7. 날짜 읽기 | 11월 9일 → 十一月九号 |
| | 8. 생일 묻기 | 你的 生日 是 几月 几号 순서 맞추기 |
| | 9. 누구의 생일? | 我的生日是十二月三十号 → 곰 카드 |
| 파티장 | 10. 퐁퐁이의 질문 | 카드 날짜(5월 21일)로 我的生日是五月二十一号 만들기 → 生日快乐! 축하 |

말판 보너스 칸: ⭐ 별, 🎁 선물(礼物), 🖐️ 손숫자 퀴즈, 💌 520 숫자 암호, 🍜 장수면(앞으로 2칸), ⏰ 시계 선물(뒤로 2칸).
끝난 학생은 **손숫자 스피드 도전**(한 번, 10문제)으로 별을 더 모을 수 있어요.
